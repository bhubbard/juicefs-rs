Workspace Crates

juicefs-core

POSIX domain types, 24-byte big-endian slice wire format, interval tree resolution, LZ4/Zstd compression.

juicefs-object

Memory, File, S3/OSS/COS/MinIO/B2, GCS, Azure, Prefixed, AES-256-GCM & 64 KiB chunked AEAD encryption, FNV-1a sharding, multipart, restore.

juicefs-chunk

moka concurrent cache, DiskBlockCache (2-Random/LRU), SingleFlight deduplication, Prefetcher, TokenBucket rate limits, async WritebackQueue.

juicefs-meta

SqliteMeta (WAL) & feature-gated RedisMeta: POSIX tree, flock/plock, dir & user/group quotas, .trash, dirStats, changelog, sessions, clone, dump/load, fsck.

juicefs-vfs

Multi-chunk I/O, sparse holes, POSIX access/ACLs, .stats/.config virtual files, compact_file, symlink loop guard, summary, warmup, tier.

juicefs-fuse

Pure-Rust POSIX FUSE adapter, file-handle table, MountConfig, and cross-platform unmount helper.

juicefs-sync

Concurrent Semaphore-bounded object sync engine with update, delete-dst, prefix, and dry-run modes.

juicefs-gateway

S3-compatible HTTP gateway over Vfs (ListObjectsV2 XML, GET/Range, HEAD, PUT, DELETE).

juicefs-webdav

WebDAV HTTP server over Vfs (OPTIONS, PROPFIND, GET/Range, HEAD, PUT, MKCOL, DELETE, MOVE, COPY, /metrics).

juicefs-metric

Lock-free atomic counters and Prometheus/OpenMetrics text exposition.

juicefs-cli

Full juicefs binary wiring 30+ subcommands for admin, I/O, sync, gateway, webdav, and benchmarks.

Quickstart

cargo build --release -p juicefs-cli
./target/release/juicefs format sqlite3:///tmp/jfs.db myvol --storage file --bucket /tmp/jfs-data --compress zstd
./target/release/juicefs mkdir -p sqlite3:///tmp/jfs.db /docs
./target/release/juicefs put sqlite3:///tmp/jfs.db ./Cargo.toml /docs/Cargo.toml
./target/release/juicefs cat sqlite3:///tmp/jfs.db /docs/Cargo.toml
